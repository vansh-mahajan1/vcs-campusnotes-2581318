# CampusNotes

A simple, shared repository of class notes for B.Tech CSE (Batch 2025-29).

Notes are organised by subject inside the `notes/` folder.

## Usage

Run `./scripts/list_notes.sh` to see every note and its title.

## Contributing

Create a branch `feature/<your-name>-<change>`, commit with Conventional Commits, and open a pull request.
